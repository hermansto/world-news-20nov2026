Entry for the make.fun bounty **"Sum up 20 November's world news in one image"** (news-image-20261120). This Node 22 program (standard library only) copies `entry.png`, a 1024×1024 front page summing up Friday 20 November 2026, byte-for-byte to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). It verifies the file is a real JPEG/PNG under 1 MiB before copying and exits non-zero otherwise.
